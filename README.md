# VTI | סוכן ההשקעות שלי

אפליקציית ווב אישית (PWA) למעקב אחרי קרן **VTI**, בעברית, מותאמת לאייפון, במצב כהה ובהיר.
הכול רץ בחינם על גיטהאב: **GitHub Pages** מגיש את האפליקציה, ו־**GitHub Actions** אוסף מחירים, מכין דוח שבועי ושולח התראות.

> מידע לימודי בלבד, לא ייעוץ השקעות. אין חיבור לחשבון Blink ואין שום פעולת קנייה או מכירה.

## מה יש באפליקציה

| מסך | מה רואים |
|---|---|
| **מצב** | שווי ההחזקה, רווח/הפסד, גרף עם קו "המחיר שקנית", הקרן מול התיק שלך, המלצת מעקב, **"מה כדאי לעשות עכשיו"** עם הסבר, כותרות מהשבוע |
| **תוכנית** | לפני שאתה לוחץ ב־Blink: כותבים קנייה/מכירה + סכום, ומקבלים הסבר — עמלות, פיזור, מס, FOMO ורגש. אחרי הביצוע רושמים ביומן והתיק מתעדכן |
| **בוט** | בוט AI (Claude) שעונה מהר בעברית, מכיר את התיק, המחיר האחרון והיומן, ורושם בעצמו פעולות שאתה מספר לו |
| **דוחות** | דוח שבועי מכל יום שישי 19:00: סגירה, שינוי שבועי, שווי, גרף השבוע, השוואה לדוח הקודם ומסקנה |
| **עוד** | התיק שלי ועמלות, התקנת ווידג׳ט, מונחים, הגדרות הבוט, מצב כהה/בהיר |

**עקרון אמינות:** אם אין מחיר ממקור — האפליקציה לא ממציאה. היא מציגה מסך הסבר.

## התקנה (10 דקות, מהאייפון או מהמחשב)

### 1. העלאה לגיטהאב
1. צור ריפו חדש בשם `vti-invest` (Public — נדרש ל־Pages בחינם).
2. **Add file → Upload files**, וגרור את כל התוכן של התיקייה (כולל `.github`).
   באייפון קל יותר: חלץ את ה־zip באפליקציית קבצים והעלה מ־github.com בדפדפן, או השתמש באפליקציה **Working Copy**.

### 2. הפעלת האתר
**Settings → Pages → Source: Deploy from a branch → main / (root) → Save.**
אחרי דקה הכתובת תהיה: `https://liors24.github.io/vti-invest/`

### 3. הרשאת כתיבה ל־Actions
**Settings → Actions → General → Workflow permissions → Read and write → Save.**

### 4. ריצה ראשונה
**Actions → Update VTI data → Run workflow** (סמן `force_report` אם תרצה גם דוח ראשון).
אחרי כדקה רענן את האתר — יופיע מחיר אמיתי.

מעכשיו זה רץ לבד: פעמיים בכל יום מסחר, ודוח בכל שישי 19:00 שעון ישראל.

### 5. עדכון התיק אחרי קנייה
ערוך את `data/portfolio.json` (כמות ומחיר ממוצע). אפשר גם לעדכן במסך **התיק** באפליקציה — אבל זה נשמר רק במכשיר, והדוחות והווידג׳ט ממשיכים לקרוא מהקובץ.

## התקנה כאפליקציה במסך הבית
ב־Safari: פתח את הכתובת → כפתור **שיתוף** → **הוספה למסך הבית**.
נפתחת במסך מלא, בלי שורת כתובת, עם אייקון משלה.

## הבוט — הגדרה חד־פעמית
1. היכנס ל־[console.anthropic.com](https://console.anthropic.com/settings/keys), הירשם והוסף אמצעי תשלום (חיוב לפי שימוש; הבוט משתמש במודל המהיר והזול Claude Haiku).
2. **Create Key** והעתק את המפתח.
3. באפליקציה: **עוד → הגדרות הבוט** → הדבק → שמירה.

**פרטיות:** המפתח, היומן והזיכרון נשמרים רק באייפון שלך (לא בגיטהאב) ונשלחים רק ל־Anthropic כשאתה שואל.
**זיכרון:** הבוט זוכר את היומן ואת מה שביקשת שיזכור. השיחה עצמה מתחילה נקייה בכל כניסה (או אחרי 30 דקות בלי פעילות). אפשר לגבות את הזיכרון לקובץ ב**הגדרות הבוט**.
**מגבלה:** לבוט אין גישה לאינטרנט. הוא מכיר רק את המחיר האחרון שה־Action אסף, ואומר זאת.

## התראות Push לאייפון (חינם, דרך ntfy)
1. התקן את אפליקציית **ntfy** מה־App Store.
2. המצא שם נושא ארוך וקשה לניחוש, לדוגמה `vti-dan-8k2q9x` (מי שיודע את השם יכול לקרוא את ההתראות).
3. ב־ntfy: **+ → Subscribe to topic** → השם שבחרת.
4. בגיטהאב: **Settings → Secrets and variables → Actions → New repository secret**
   שם: `NTFY_TOPIC`, ערך: השם שבחרת.
5. (רשות) ב־**Variables** הוסף `SITE_URL` עם כתובת האתר, כדי שלחיצה על ההתראה תפתח את הדוח.

מתי נשלחת התראה: דוח שבועי מוכן; תנועה יומית של 3% ומעלה; שבועית של 5% ומעלה; ירידה של 20% מהשיא השנתי. **לא** על כל תנודה רגילה, ורק פעם אחת לכל יום מסחר.
הסקריפט רושם התראה כנשלחה רק אם שרת ntfy אישר אותה.

## ווידג׳ט למסך הבית ולמסך הנעילה

לווידג׳ט אמיתי עם נתונים חיים משתמשים באפליקציה החינמית **Scriptable** (קיצורים לבד לא יודעים להציג נתונים בתוך ווידג׳ט).

1. התקן **Scriptable** מה־App Store.
2. פתח אותה → **+** → הדבק את כל התוכן של `widget/vti-widget.js`.
3. בשורה `const SITE = ...` שים את הכתובת שלך (עם `/` בסוף). שם לסקריפט: `VTI`.
4. לחץ ▶ לבדיקה — אמור להופיע כרטיס עם השווי שלך.
5. במסך הבית: לחיצה ארוכה → **+** → **Scriptable** → בחר גודל **קטן** או **בינוני** → הוסף.
6. לחיצה ארוכה על הווידג׳ט → **ערוך ווידג׳ט** → Script: **VTI**, When Interacting: **Open URL** (הווידג׳ט כבר מוגדר לפתוח את האפליקציה).
7. מסך נעילה: לחיצה ארוכה על מסך הנעילה → **התאמה אישית** → הוסף ווידג׳ט **Scriptable** מלבני → בחר **VTI**.

מה מוצג: שווי משוער, רווח/הפסד בדולר ובאחוז, גרף 3 חודשים (בבינוני), שינוי יומי בקרן, נקודת צבע של המלצת המעקב וזמן העדכון. אם אין רשת — מוצגים הנתונים השמורים עם הכיתוב "שמור".

## קיצור דרך (Shortcuts)

**קיצור "מצב VTI" — שואל ומקריא לך, גם דרך Siri:**
1. אפליקציית **קיצורים** → **+**.
2. הוסף פעולה **קבל תוכן של URL** → `https://liors24.github.io/vti-invest/data/vti.json`
3. הוסף **קבל ערך ממילון** → מפתח `portfolio` → ואחריו **קבל ערך ממילון** → `value`.
4. הוסף **הצג תוצאה** (או **דבר טקסט**) עם: `שווי VTI שלך: $` + הערך.
5. שם לקיצור: **מצב VTI**. עכשיו אפשר לומר "היי סירי, מצב VTI".

**קיצור לפתיחת האפליקציה:**
פעולה אחת: **פתח כתובות URL** → כתובת האתר. בהגדרות הקיצור → **הוסף למסך הבית** (אפשר לבחור אייקון). את הקיצור אפשר להוסיף גם כווידג׳ט **קיצורים** כדי שיהיה כפתור על מסך הבית.

**שילוב עם הווידג׳ט:** בהגדרות ווידג׳ט Scriptable אפשר לבחור When Interacting → **Run Shortcut** → "מצב VTI".

## חשוב לדעת
- **מקורות:** מחיר והיסטוריה מ־Yahoo Finance (גיבוי: Stooq). כותרות מ־Yahoo Finance באנגלית — כותרות בלבד, לא ניתוח.
- **עיכוב:** הנתונים מתעדכנים פעמיים ביום מסחר, לא בזמן אמת. השעה מוצגת תמיד ליד המחיר.
- **תזמון:** GitHub לפעמים מאחר בהרצות מתוזמנות ב־10–30 דקות.
- **ריפו ציבורי:** קובץ התיק גלוי לכל מי שמוצא את הריפו. אם זה מפריע — אפשר לשמור את התיק רק במכשיר (מסך התיק), ואז הדוחות והווידג׳ט יחשבו לפי הקובץ שבגיטהאב.
- **החישוב משוער:** לא כולל עמלות, מס והמרת מטבע, ואינו היתרה הרשמית ב־Blink.
