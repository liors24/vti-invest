    מה קרה בשוק

      לפני שאתה לוחץ ב־Blink

      כתוב מה אתה מתכנן, ותקבל הסבר אם זה הגיוני — לפני שאתה מבצע.

      שני דברים לבדוק על עצמך

      היומן שלי

      כל פעולה שרשמת — כאן ובבוט. הבוט קורא את היומן כדי לזכור מה עשית.

        הבוט שלך

        דוחות שבועיים

        נוצרים אוטומטית בכל יום שישי ב־19:00 שעון ישראל.

        עוד

        התיק שליכמות, מחיר קנייה ועמלות ווידג׳ט לאייפוןהשווי שלך על מסך הבית ללמוד בקטנהמונחים בעברית פשוטה הגדרות הבוטמפתח, זיכרון ופרטיות

        תצוגה

        פרטיות

        אין כאן חיבור לחשבון Blink, ואין שום פעולת קנייה או מכירה. התיק, היומן והזיכרון של הבוט נשמרים רק במכשיר הזה.

        › עוד

        התיק שלי

        עדכן אחרי כל קנייה ב־Blink. כדי שגם הדוחות השבועיים יתעדכנו, עדכן גם את data/portfolio.json בגיטהאב.

        › עוד

        ווידג׳ט לאייפון

        אייפון מאפשר ווידג׳טים רק לאפליקציות מה־App Store. לכן הווידג׳ט רץ דרך האפליקציה החינמית Scriptable, ומציג את אותם נתונים כמו כאן.

        1. התקן את Scriptable מה־App Store
        3. פתח את Scriptable, לחץ +, הדבק, ותן לסקריפט את השם VTI. פתח את Scriptable
        4. במסך הבית: לחיצה ארוכה ← + ← Scriptable ← גודל קטן או בינוני ← הוסף ווידג׳ט.
        5. לחיצה ארוכה על הווידג׳ט ← ערוך ווידג׳ט ← Script: VTI.
        6. למסך הנעילה: לחיצה ארוכה על מסך הנעילה ← התאמה אישית ← הוסף ווידג׳ט Scriptable מלבני ← VTI.

        הגדרות הבוט

        המפתח נשמר רק במכשיר הזה ונשלח רק ל־Anthropic. אל תשתף אותו ואל תעלה אותו לגיטהאב. יוצרים מפתח ב־console.anthropic.com; החיוב לפי שימוש.

        מה הבוט זוכר

        היומן שלך והדברים שביקשת שיזכור. השיחה עצמה מתחילה נקייה בכל כניסה חדשה — הזיכרון נשאר.
